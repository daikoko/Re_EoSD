# Definitely Not EoSD
This is a fan-remake of Touhou 6: Embodiment of Scarlet Devil. Source code released under MIT license.

Itchio Page: https://daikoko.itch.io/not-eosd

## Installation
This project is made in Godot 4.3 and you will need that version of the engine to run the source code. Otherwise, you can download the plain executable from the Itchio page.

## Features
- 3 Playable Characters
- 6 Total Shot Types
- 3 Game Modes
- 4 Difficulties
- 6 Main Stages plus 1 Extra and 1 Phantasm Stage
